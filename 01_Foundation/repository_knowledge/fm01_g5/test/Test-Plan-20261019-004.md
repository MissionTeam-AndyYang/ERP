## 3. Test classification model

- `UNIT`: pure domain/service rule with isolated data.
- `CONTRACT`: request/response, error envelope, field and route contract.
- `STATIC`: source, migration, schema, route, dependency and policy inspection.
- `MOCK`: synthetic actor/approval/audit/DB adapter without live target contact.
- `NON_DB`: local disposable execution with no target database or runtime.
- `DB_DEPENDENT`: named non-Production target, fixture, permissions and readback required.
- `E2E`: authorized UI/API/database/audit flow against a named non-Production target.

Prospective mutation, UI, DB and E2E cases are design cases only. They have no execution result.
